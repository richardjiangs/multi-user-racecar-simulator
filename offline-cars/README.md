# Individual offline simulators

Download a car’s HTML file, then open that file in a current browser. Each download works by itself without a server, assets folder or internet connection. Track 1.0 and Track 2.0 are retained separately; the Phantom has its existing single edition.

All simulator source, controls, maps, artwork, audio synthesis and route geometry are retained. The builder selects the smaller complete file from maximum-level Brotli and gzip, including decoder overhead. Large coordinate tables also use exact integer deltas where every original value is reproduced exactly. No image downsampling, geometry simplification or reduced-quality settings are used. Track 2.0 worlds are reconstructed in a worker and checked against the original vertex and batch SHA-256 hashes before driving.
